# CLOTH Studio — Archive 2026

A high-end, brutalist minimalist fashion platform. Engineered for visual consistency, modular technical data documentation, and premium e-commerce interactions.

Live Demo : [Cloth](https://harshalloke.github.io/clothing/)

## Technical Stack
- **Core**: HTML5, Vanilla JavaScript
- **Styling**: Tailwind CSS (JIT Engine)
- **Animations**: GSAP (GreenSock Animation Platform) + ScrollTrigger
- **Experience**: Lenis Smooth Scroll
- **Architecture**: Mobile-First Technical Journaling

## Project Structure
```text
├── assets/
│   └── img/           # Technical product assets and documentation visuals
├── css/
│   └── main.css       # Core design system and global overrides
├── js/
│   ├── main.js        # Global systems and state management (Cart/Registry)
│   └── animations.js  # Dedicated interaction and entrance protocols
├── index.html         # Repository entry point
├── shop.html          # Collection catalogue
├── product.html       # Article detailed specification
├── archive.html       # Chronological design legacy
└── cart.html          # Secure registry / Checkout interface
```

## Protocol
Designed with a focus on institutional aesthetics and high-impact typography. The platform utilizes a 12-column grid system with specialized chronological markers for the archive repository.
